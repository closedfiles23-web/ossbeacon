# Governance

OSSBeacon currently uses a lightweight maintainer-led model.

## Maintainer responsibilities
Maintainers review contributions, triage issues, publish releases, protect project security, and keep public decisions understandable.

## Becoming a maintainer
Regular contributors who demonstrate good technical judgment, respectful collaboration, reliable review participation, and alignment with the project's safety and privacy principles may be invited as maintainers.

## Decision making
Small changes use normal pull-request review. Larger changes should start with a public issue or discussion so tradeoffs are visible before implementation.

As the maintainer group grows, this document should evolve toward explicit voting, release, and succession procedures.

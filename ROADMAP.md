# OSSBeacon Roadmap

This roadmap is directional, not a promise of delivery dates.

## v0.1: useful baseline
- [x] PR risk scoring
- [x] Review checklist
- [x] Issue triage
- [x] Release note grouping
- [x] Optional OpenAI summaries
- [x] Composite GitHub Action
- [x] Zero runtime dependencies

## v0.2: maintainer ergonomics
- [ ] Stable machine-readable report schema
- [ ] Repository policy packs
- [ ] Duplicate issue candidate hints
- [ ] Better monorepo path weighting
- [ ] Comment update instead of repeated comments
- [ ] More fixture-based integration tests

## v0.3: ecosystem integration
- [ ] SARIF output for review signals
- [ ] Provider adapter interface
- [ ] GitLab metadata adapter
- [ ] Release-note templates
- [ ] Public benchmark repository for triage rules

## v1.0: dependable maintainer tool
- [ ] Stable CLI contract
- [ ] Documented plugin API
- [ ] Security review
- [ ] Reproducible release process
- [ ] Maintainer governance document
